1. Check the mod version in Source/Common/Version.cs.
2. Check supported RimWorld versions in About/About.xml and LoadFolders.xml.
3. Check About/Preview.png.
4. Preserve a release branch for older RimWorld versions when dropping support.
5. Push the release tag (v*) or manually run the Build workshop workflow.
6. Download the Multiplayer-<tag-or-branch> artifact from the workflow run. It contains Multiplayer/ with both supported version folders and a generated modVersion.
7. Use the downloaded ZIP for GitHub releases and the extracted Multiplayer/ folder for the Steam Workshop upload.
